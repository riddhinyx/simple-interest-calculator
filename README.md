# Simple Interest Calculator

A Bash calculator that computes simple interest from a principal amount, an annual interest rate, and a time period in years. Created for the Getting Started with Git and GitHub final project.

## Formula

`simple interest = principal × annual rate × time / 100`

The rate is entered as a percentage: enter `5` for 5% per year.

## Requirements

Bash and awk, available on macOS and most Linux systems.

## Run

```bash
bash simple-interest.sh
```

Enter the following values when prompted:

- Principal amount, such as `1000`
- Annual interest rate in percent, such as `5`
- Time period in years, such as `2`

The example produces `The simple interest is: 100.00`.
Inputs may be nonnegative integers or decimal numbers. Invalid or missing input exits with an error.
