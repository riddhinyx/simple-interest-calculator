# Contributing

All contributions, bug reports, bug fixes, documentation improvements, enhancements, and ideas are welcome.

1. Open an issue describing the proposed change or bug.
2. Fork the repository and create a branch for your change.
3. Make your change and check that the calculator still works.
4. Open a pull request describing your change and how you checked it.

Follow the [Code of Conduct](CODE_OF_CONDUCT.md) in all project interactions.
